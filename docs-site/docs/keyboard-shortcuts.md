# Keyboard Shortcuts

These shortcuts work in the desktop layout (wide browser windows and the desktop app). On macOS, use ⌘ in place of Ctrl and ⌥ (Option) in place of Alt.

| Shortcut | What it does |
|---|---|
| Alt+↑ / Alt+↓ | Previous / next text channel in the sidebar, or previous / next conversation in Direct Messages |
| Alt+Shift+↑ / Alt+Shift+↓ | Previous / next unread channel or conversation in the same list |
| Esc | Close the open thread, pinned messages or search panel; with none open, mark the conversation read |
| ↑ (in an empty message box) | Edit your last message |
| Ctrl+/ | Show the list of shortcuts (also **Keyboard shortcuts** in the account menu) |

Notes:

- Channel navigation skips voice channels, because opening one joins the call.
- The navigation keys and Esc work from the message box but not from other text fields. Ctrl+/ works everywhere.
- If your push-to-talk key is one of these keys, push-to-talk takes priority.
- On Windows, and on Linux desktops set up that way, Alt+Shift can also switch the keyboard layout.
